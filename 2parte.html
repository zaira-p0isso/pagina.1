CSS simple y diseño

1. ¿Qué es CSS y para qué sirve?

Si el HTML era el esqueleto o los ladrillos de tu casa, el CSS (Cascading Style Sheets o Hojas de Estilo en Cascada) es la pintura, la decoración, los muebles y el diseño exterior.

Mientras que el HTML define qué cosas hay en la pantalla (textos, títulos, imágenes), el CSS se encarga de darles color, cambiar las fuentes, ordenar los espacios y ponerle una hermosa foto de fondo a tu página web.

2. El puente mágico: Cómo conectar CSS y HTML

Para que tu página web sepa qué diseño usar, debes vincular tu archivo style.css dentro de la sección <head> de tu HTML. Se hace con una sola línea de código como esta: 

<link rel="stylesheet" href="style.css">

¡Ojo aquí! Así como pasaba con las imágenes o los enlaces, es muy importante que tu archivo de estilos se llame exactamente style.css y esté guardado en la misma carpeta que tus páginas HTML.

3. La estructura secreta del CSS

A diferencia del HTML (que usa etiquetas como <p>), el CSS funciona dando "órdenes" a los elementos usando llaves { }. Su formato básico se compone de un selector y sus propiedades: 

selector {
    propiedad: valor;
}

4. Un ejemplo de código CSS simple

Así se ve un ejemplo real dentro de style.css para cambiar el tipo de letra, poner una foto de fondo y darle estilo a un título: 

/* Ejemplo de CSS básico */
body {
    font-family: Arial, sans-serif;
    background-image: url('fondo.jpg');
    background-size: cover;
    color: white;
}

h1 {
    text-align: center;
    color: #3498db;
}

5. Lo que hace nuestro archivo style.css actual

Si abres tu archivo style.css en Visual Studio Code, verás que cada bloque cumple una función muy clara y sencilla:

  • body { ... }: Controla toda la página por completo. Aquí colocamos la foto de fondo (background-image), el tamaño de la letra y el color blanco general del texto.
  • header { ... }: Diseña la barra superior oscura donde se ubica el título principal de bienvenida.
  • .contenedor { ... }: Es la caja invisible que limita el ancho del texto para que no se estire demasiado en pantallas grandes y se lea de forma cómoda.
  • .navegacion a { ... }: Da el aspecto de botón azul brillante a tus enlaces para pasar de una página a otra con total facilidad.
