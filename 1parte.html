Html simple

1. Organizar tu espacio de trabajo

Todo proyecto web ordenado empieza creando una carpeta nueva en tu computadora (por ejemplo, llamada mi-pagina-web). Esa carpeta será tu centro de operaciones y allí es donde vas a guardar absolutamente todo lo que forme parte de tu sitio: tus páginas HTML, tus fotos, tus imágenes de fondo y tus hojas de estilo CSS.

Luego, abre tu editor de código gratuito preferido —como Visual Studio Code (VS Code)— y arrastra o abre esa carpeta dentro del programa. Al hacerlo, verás todos tus archivos organizados en el panel izquierdo listos para trabajar.

2. ¿Qué es HTML y cómo funciona?

HTML significa HyperText Markup Language (Lenguaje de Marcas de Hipertexto). Para entenderlo de forma muy simple, es el esqueleto o la estructura de tu página web: se encarga de definir qué elementos van en pantalla (los títulos, los textos, las imágenes y los enlaces que te permiten pasar de una página a otra).

3. Las tres partes mágicas: <head>, <header> y <body>

Cuando miras un código HTML por primera vez, vas a ver estas tres palabras muy seguido. ¡No te confundas, cada una hace algo distinto!:

  • <head> (La cabeza / Configuración): Va arriba del todo, antes de que empiece la página visible. Aquí se guardan los datos "invisibles" para el visitante, como el título que aparece en la pestaña del navegador y la conexión con tu archivo de diseño (CSS).
  • <body> (El cuerpo / Todo lo visible): Es la etiqueta que envuelve absolutamente todo lo que va a aparecer en la pantalla de tu página web (textos, fotos, botones).
  • <header> (La cabecera visual): A diferencia del head, este va dentro del body y sirve para poner el bloque de arriba de tu página, como el título principal de bienvenida que ven tus usuarios.

3.5. ¿Qué son esas etiquetas <meta> dentro del <head>?

Cuando creas un archivo HTML, verás que adentro del <head> aparecen dos líneas un poco raras llamadas <meta>. Aunque parezcan difíciles, cumplen dos tareas súper simples:

  • <meta charset="UTF-8">: Permite que la página muestre bien las tildes (á, é, í, ó, ú), los signos de interrogación y la letra ñ sin que salgan símbolos extraños.
  • <meta name="viewport" ...>: Hace que tu página web se ajuste automáticamente al tamaño de la pantalla, para que se vea bien tanto en una computadora como en un celular.

💡 Truco rápido en Visual Studio Code: No tienes que escribir todo esto de memoria. Si en un archivo vacío escribes ! y presionas la tecla Enter, el programa te creará toda esta estructura automáticamente.

4. Etiquetas para escribir el contenido

Dentro del cuerpo de la página, usamos etiquetas básicas encerradas entre los símbolos < y >:

  • <h1>: Sirve para poner el título más grande e importante.
  • <p>: Sirve para escribir párrafos de texto normal.
  • <a>: Sirve para crear los enlaces que te llevan de una página a otra (usando href="...").

5. Un ejemplo de código HTML simple

Así es como se vería por dentro un documento HTML básico juntando todo esto: 

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <title>Mi primera página</title>
</head>
<body>
    <header>
        <h1>¡Hola mundo!</h1>
    </header>
    
    <p>Este es mi primer párrafo escrito con HTML.</p>
    <a href="index.html">Volver al inicio</a>
</body>
</html>

¿Cómo funcionan los enlaces con <a>?

La etiqueta <a> sirve para crear enlaces (links) que permiten moverse de una página a otra dentro de tu proyecto o hacia otra web. 

<a href="parte2.html">Ir al Paso 2</a>
  • <a> y </a>: Abren y cierran el enlace.
  • href="parte2.html": Indica el destino al que va a llevar el clic (el nombre exacto del archivo guardado en tu carpeta).
  • Ir al Paso 2: Es el texto visible que verá el visitante en pantalla para hacer clic.
